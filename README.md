# Шахматы 9×9

Шахматы на доске 9×9 прямо в браузере: можно играть вдвоём за одним экраном или против компьютера. Без сборки и зависимостей — только HTML, CSS и JavaScript.

## Как запустить

Откройте `index.html` в браузере. Или запустите локальный сервер:

```bash
npm start
```

## Расстановка

Фигуры на крайних горизонталях стоят так (слева направо, вертикали a–i):

```
Л  К  С  Ф  Кр  С  К  К  Л
```

Девять пешек на каждой стороне. Добавлен лишний конь, чтобы заполнить девятую вертикаль. Расстановку можно поменять в одной строке: массив `BACK_RANK` в `js/engine.js`.

## Правила

Работают все правила обычных шахмат:

- ходы фигур, шах, мат и пат;
- короткая и длинная рокировка (король идёт на две клетки, ладьи стоят в углах a и i);
- взятие на проходе;
- превращение пешки в ферзя, ладью, слона или коня (выбор через окно);
- ничья: недостаточно материала, правило 50 ходов, троекратное повторение позиции.

## Интерфейс

- подсветка возможных ходов, последнего хода и шаха;
- список ходов в алгебраической записи и взятые фигуры;
- отмена хода и поворот доски;
- режим против компьютера с тремя уровнями сложности (лёгкий, средний, сильный) и выбором стороны.

## Компьютерный соперник

Перебор ходов (минимакс с альфа-бета отсечением) и оценка по материалу и положению фигур. Играет в полную силу не как профессиональный движок, но против новичка вполне достаточно.

## Тесты

```bash
npm test
```

Тесты движка проверяют начальную расстановку, мат, пат, оба вида рокировки, взятие на проходе, превращение, связки, отмену хода и 40 случайных партий подряд.

## Структура

```
index.html        страница
css/style.css     оформление
js/engine.js      правила и генерация ходов
js/ai.js          компьютерный соперник
js/app.js         интерфейс
test/             тесты движка
```
